# 🌤️ MyWeatherForecast - Capstone Project

## 💡 Project Idea

MyWeatherForecast is a clean, interactive weather web app that allows users to search any city and get real-time weather data including temperature, humidity, wind speed, visibility, pressure, sunrise/sunset, and more—beautifully styled and responsive for all screens.

## 🔧 Technologies Used

- HTML, CSS, JavaScript
- OpenWeatherMap API
- LocalStorage
- Responsive UI
- .env for API key management (in production)
